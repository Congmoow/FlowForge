# FlowForge

FlowForge 是一款节点式可视化 AI 工作流编辑器，目标是用 Avalonia 与 .NET 8 构建一个本地运行的桌面端作品集项目。

> 当前仓库处于 Stage 1 骨架阶段，功能实现会按 `AGENTS.md` 中的里程碑逐步推进。

## 快速开始

```powershell
dotnet restore
dotnet build
dotnet test
```

## 当前目标

- 搭建 Avalonia 桌面应用骨架。
- 建立 Core、App、测试项目与 CI 基础设施。
- 后续按 Stage 2 到 Stage 6 完成节点画布、执行引擎、序列化、插件与发布流程。
