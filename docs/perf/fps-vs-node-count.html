测量口径

  • 窗口：1200 × 760 logical px。
  • 场景：确定性 100 / 250 / 500 / 1000 节点压力场景。
  • seed：20260803；自动平移间隔 8ms。
  • 每档预热 5 秒，随后自动平移 30 秒。
  • 每秒一个样本；FPS 来自实际 NodeCanvas.Render 次数。
  • 内存为进程 Process.WorkingSet64 峰值；表中 MiB 使用 1 MiB = 1,048,576 bytes。

运行环境

  • CPU：12th Gen Intel Core i5-12450H，8 physical / 12 logical。
  • GPU：Intel(R) UHD Graphics；同时检测到 GameViewer Virtual Display Adapter。
  • OS：Microsoft Windows 11 家庭版中文版，build 26200。
  • .NET SDK：8.0.302；运行时：8.0.7；RID：win-x64。
  • Avalonia：11.2.3。

运行入口与截图

dotnet run --project src/FlowForge.App/FlowForge.App.csproj --configuration Release --no-build -- --perf --nodes <100|250|500|1000> --output artifacts/perf/fps-<N>-b0005bf.json
